## 自动化范围

后端AnswerServiceTest与ApiTest覆盖：

- 单选、多选、判断的评分；集合顺序不影响结果，少选和未答为0。
- 创建/恢复答卷、已保存答案恢复和版本冲突。
- 非本人的答卷访问、学生访问统计、教师访问他人考试受限。
- 无效题目批量保存不产生部分写入、无效选项和重复选项拒绝。
- 已提交禁止修改，重复提交返回同一成绩。
- 服务端扫描逾期记录，生成AUTO_SUBMITTED成绩。
- 并发开始只有一份答卷，并发提交只有一条成绩。
- 空统计、统计只纳入已评分记录、未来考试和不存在考试校验。
- HTTP缺少或伪造身份返回401，格式错误返回400，响应不泄露标准答案，时间符合约定。

前端Node测试覆盖剩余时间下限、清空答案保存以及保存任务串行执行和失败恢复。
